## KEYCLOAK

[Resource](https://www.youtube.com/watch?v=7Ict7nML-Yo&t=46s)

Keycloak is an open-source Identity and Access Management (IAM) solution that enables Single Sign-On (SSO) and robust access control for modern applications and services. It simplifies authentication and authorization, allowing developers to focus on core business logic rather than building security from scratch.
